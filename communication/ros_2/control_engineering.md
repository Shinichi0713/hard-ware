## 制御の基礎理論
ロボット制御におけるモータ制御の基礎理論は、大きく分けて「古典制御」と「現代制御」の2つに分類できます。以下、代表的な理論を基礎から順にご説明します。

### 1. 古典制御（フィードバック制御）

__PID制御__

最も広く使われる制御手法です。目標値と現在値の偏差（エラー）に対して、比例・積分・微分の3つの操作を組み合わせて制御入力を決定します。

- **P（比例）**: 現在のエラーに比例した操作量を出力。大きいほど応答が速くなるが、振動しやすくなる。
- **I（積分）**: 過去のエラーの累積に比例した操作量を出力。定常偏差（オフセット）を解消する。
- **D（微分）**: エラーの変化率に比例した操作量を出力。将来のエラーを予測し、振動を抑制する。

ロボットの関節角度制御や車輪の速度制御など、多くの現場で標準的に採用されています。

__Bang-Bang制御（ON/OFF制御）__

最も単純な制御で、目標値に達するまでモータをフル出力で駆動し、達したら停止するという方式です。ヒーターや簡易的な位置決めなどに使われますが、ロボットの精密制御にはあまり適しません。

### 2. フィードフォワード制御

PIDは「エラーが発生してから」修正するフィードバック制御ですが、フィードフォワード制御は「事前にわかっている情報」を使って、エラーが起きる前に必要な操作量を出します。

__DCモータのフィードフォワード__

DCモータの物理モデルに基づき、以下の要素を事前に補償します。

- **速度項（Kv）**: 目標速度に比例した電圧
- **加速度項（Ka）**: 目標加速度に比例した電圧
- **摩擦・重力補償**: ロボットアームなどでは重力や摩擦を事前に打ち消す

実際には「フィードフォワード + PIDフィードバック」を組み合わせることで、高速かつ正確な追従制御が実現されます。

### 3. 現代制御（状態空間アプローチ）

__LQR（Linear Quadratic Regulator）__

状態空間モデルに基づく最適制御の一種です。ロボットの「位置・速度」などの状態変数を使い、ある評価関数（コスト関数）を最小化するような制御入力を解析的に求めます。

- 複数の入力・複数の出力を同時に扱える
- 最適なゲインが自動的に計算される
- 倒立振子や二足歩行ロボットの安定化に広く使われる

__MPC（Model Predictive Control）__

モデル予測制御です。ロボットの動力学モデルを使い、未来の数ステップ先までの動きを予測しながら、最適な制御入力を逐次計算します。

- 拘束条件（関節角の可動範囲・トルク制限など）を明示的に考慮できる
- 人型ロボットや自律走行車など、複雑なシステムで近年注目されている

### 4. 力・インピーダンス制御

位置や速度だけでなく、環境との接触力を制御する理論です。

__力制御（Force Control）__

ロボットが環境に押し付ける力を直接制御します。研磨・組み立て作業などに重要です。

__インピーダンス制御（Impedance Control）__

位置と力の関係（バネ・ダンパー的な特性）を制御します。環境との接触が予期せぬ場合でも、柔軟に対応できるため、安全な協働ロボットに広く使われています。

__ハイブリッド位置・力制御__

一部の自由度では位置を、残りの自由度では力を同時に制御する方式です。例えば、壁に沿って運動させる場合、壁面方向には力を、進行方向には位置を制御します。

## 現代制御の優位性

現代制御が古典制御に対する優位性は2点あります。
1. 多変数を扱えること
2. システムの内部状態を直接扱う状態空間表現

以下、順を追って説明します。

### 1. 多変数制御は「結果」であり「手段」ではない

古典制御は伝達関数（入出力の関係）を扱います。これは本質的に**1入力1出力（SISO）** の記述です。複数の入出力がある場合、伝達関数行列を使うことはできますが、各入出力間の結合（干渉）を設計に組み込むのが困難です。

現代制御では状態空間表現を使うため、状態変数の数、入力の数、出力の数が独立に定義できます。これにより複数のアクチュエータと複数のセンサを持つシステムを自然に記述できます。

ただし、多変数を扱えるのは**状態空間表現を使うから**であり、多変数そのものが目的ではありません。

### 2. 現代制御の真の優位性：内部状態の可視化と操作

__古典制御の限界__

伝達関数では「入力に対して出力がどうなるか」しか表現できません。例えばロボットアームの場合、「関節角度」と「関節角速度」は密接に関連していますが、伝達関数では角速度が内部的にどう変化しているかを直接扱えません。

__現代制御のアプローチ__

状態空間表現では、位置・速度・加速度などの**内部状態をベクトルとして直接扱えます**。これにより以下が可能になります。

- **オブザーバ（状態推定器）**: センサで測れない状態（例：速度を直接測らずに位置から推定）を推定して制御に使える
- **ポール配置**: システムの応答特性（収束の速さ・振動の減衰）を意図的に設計できる
- **不安定系の安定化**: 倒立振子など、開ループで不安定なシステムを状態フィードバックで安定化できる

### 3. 最適化の枠組み

現代制御の大きな特徴は、**「最適な制御則を自動的に導出できる」** 点です。

__LQRの例__

状態と入力の二乗和を最小化するコスト関数を定義すれば、Riccati方程式を解くことで最適ゲインが解析的に求まります。PIDではゲイン調整が試行錯誤的ですが、LQRでは「何を最適化したいか」を定式化すれば、最適な制御則が機械的に導出されます。

これは多変数制御とは別の、**設計方法論としての優位性**です。

### 4. 制約条件の明示的な扱い（MPC）

現実のロボットには物理的な制約が存在します。

- モータの最大トルク
- 関節の可動範囲
- 障害物との距離

古典制御ではこれらの制約を制御則に組み込むのが極めて困難です。MPC（モデル予測制御）は、未来の状態を予測しながら**制約付き最適化問題**を逐次解くことで、これらを自然に扱えます。これも状態空間表現が基盤にあるから実現できることです。

### 補足：古典制御が依然として有効な理由

現代制御が万能ではありません。モデルが正確でない場合、状態空間表現に基づく設計は誤ったモデルに依存してしまいます。PIDのような古典制御は「モデルが不要」という強みを持ち、現場での調整ノウハウも豊富です。

したがって、現代制御の優位性は「多変数だから」というより、**「状態空間表現というより豊かな記述能力を持つから」** であり、多変数制御はその能力の一つの表れと言えます。

## 使い分け

古典制御と現代制御の使い分けは、制御対象の複雑さ、性能要求、設計・調整の容易さのバランスで決まります。以下に両者の違いと具体的な使い分けの指針をまとめます。

### 1. 古典制御が適している場面

__特徴__

古典制御（PID、周波数応答法、ルート軌跡法）は、入出力の関係（伝達関数）に基づくアプローチです。直感的で実装が容易であり、1入力1出力（SISO）のシステムに特に強みを発揮します。

__適用例__
- **単軸のモータ位置・速度制御**: エンコーダフィードバックによる関節制御など、入出力が明確なシステム
- **既存システムの微調整**: 経験則（Ziegler-Nichols法など）でゲインを調整し、迅速に運用開始
- **モデルが不明確な場合**: 厳密な物理モデルが不要で、実験的にゲインを決定可能
- **計算リソースが限られた環境**: 組み込みマイコンやFPGAでの軽量実装

WPILibの文書でも、PIDは「現在・過去・未来のエラーに対するパラメータ調整」に集中する実用的な手法として位置づけられています。

### 2. 現代制御が適している場面

__特徴__

現代制御（状態空間法、LQR、MPC）は、システムの**内部状態（位置・速度・加速度など）** を直接扱います。多入力多出力（MIMO）システムや、複雑な拘束条件を持つ問題で優位性があります。

__現代制御が特に有効な場面__

__(1) 複数の状態を同時に制御する必要がある場合__

ロボットアームの各関節は、位置・速度・加速度が互いに影響し合います。状態空間表現ではこれらをベクトルとして一括処理でき、LQRで最適な制御入力を一括計算できます。

__(2) 拘束条件を明示的に扱う必要がある場合__

関節角の可動範囲、トルク制限、障害物回避などの制約を満たしながら最適な動作を生成する必要がある場合、MPCは「未来を予測しながら制約付き最適化」を行うため、古典制御では不可能な制御が実現できます。

__(3) 不安定なシステムの安定化__

倒立振子や二足歩行ロボットなど、自然状態では倒れてしまう不安定系に対して、状態フィードバック（LQR）やオブザーバによる状態推定が有効です。PIDだけでは位相余裕が不足し、安定化が困難な場合があります。

__(4) 性能の最適化が重要な場合__

エネルギー消費の最小化、到達時間の最短化、振動の抑制など、明確な評価指標（コスト関数）に対して最適な制御則を解析的に求めたい場合、LQRや最適制御が適しています。

__(5) 外部擾乱やモデル誤差への対応が重要な場合__

オブザーバ（状態推定器）を組み合わせることで、測定できない状態を推定し、擾動に対してロバストな制御が可能になります。これは古典制御の範囲を超える機能です。

### 3. ロボット制御における具体的な使い分け

| 制御対象 | 推奨方式 | 理由 |
|---------|---------|------|
| 車輪の速度制御 | PID | 単純なSISO系で十分 |
| 関節の位置決め | PID + フィードフォワード | 実装が容易で十分な性能 |
| 倒立振子の安定化 | LQR + オブザーバ | 不安定系の安定化に最適 |
| 二足歩行の全身制御 | MPC / Whole-body QP | 複数の拘束条件を同時に考慮 |
| ドローンの姿勢制御 | LQR or PID + ゲインスケジューリング | 非線形性とMIMO特性の両立 |
| 協働ロボットの力制御 | インピーダンス制御 / MPC | 環境との接触力を制御 |

### 4. 実用上の指針

__まず古典制御から始める__

多くのロボット制御では、まずPIDで要件を満たせるか確認します。実装が容易で、現場での調整ノウハウも豊富です。

__以下の場合に現代制御を検討する__
- PIDだけでは振動が抑制できない
- 複数の関節や自由度が強く結合している
- 可動範囲やトルク制限などの拘束条件が厳しい
- エネルギー効率や追従精度の最適化が重要
- システムが本質的に不安定

__ハイブリッドアプローチが現実的__

実際のロボット開発では、古典制御と現代制御を組み合わせることが一般的です。例えば、関節単位ではPIDを使いつつ、全体の動作計画にはMPCを使う、あるいはLQRで設計したゲインをPIDの近似として実装するなど、段階的な移行も有効です。

## 仮想環境

制御（状態空間、LQR、MPCなど）を体験できる環境は、ブラウザで即座に試せるものから、Pythonで本格的に実装できるものまで複数あります。以下に代表的なものを紹介します。

### 1. ブラウザで即座に体験できるオンラインシミュレータ

__Neutron STEM Lab Control System Simulator__

PIDだけでなく、状態空間モデル、ステップ応答、ボード線図までブラウザ上でシミュレーション可能です。アカウント不要で、ブロック図を組みながら制御系の動作を直感的に理解できます。[Neutron STEM Lab](https://neutronstemlab.com/tools/controls/control-system-simulator/)

__SysDynLab__

より高度なブロック図シミュレータで、積分器、微分器、伝達関数、PID、状態機械、行列演算などをサポートしています。状態空間系をブロック図で組んでシミュレーションできます。[SysDynLab](https://sim.sysdynlab.com/)

__PhysSandbox Cart-Pole Simulator__

倒立振子（カートポール）に対して、PID・LQR・MPCの3つを同じ条件下で比較シミュレーションできる優れた教育ツールです。LQRとMPCの違いを視覚的に体験できます。[PhysSandbox](https://physandbox.com/engineering/cart-pole-lqr)

### 2. Pythonで手軽に本格的な現代制御を体験

__Python Control Systems Library (python-control)__

MATLABのControl System Toolboxに相当するPythonライブラリです。状態空間モデルの作成、LQRゲインの計算（`control.lqr()`）、ステップ応答、オブザーバ設計まで一貫して行えます。Jupyter Notebookで対話的に学習できるチュートリアルも充実しています。[Python Control Systems Library](https://python-control.readthedocs.io/en/latest/statesp.html)

LQRの計算は以下のように簡潔に書けます。

```python
import control as ct
import numpy as np

# 状態空間モデル (例: 倒立振子)
A = np.array([[0, 1], [10, 0]])  # 簡易モデル
B = np.array([[0], [1]])

# LQRコスト重み
Q = np.diag([10, 1])  # 状態の重み
R = np.array([[1]])    # 入力の重み

K, S, E = ct.lqr(A, B, Q, R)
print("LQRゲイン K =", K)
```

垂直離着陸機（VTOL）のLQR設計例も公開されており、実用的なモデルで現代制御を学べます。[VTOL LQR Example](https://python-control.readthedocs.io/en/latest/examples/pvtol-lqr.html)

### 3. ロボットシミュレータでMPC・LQRを体験

__MuJoCo MPC (DeepMind)__

Google DeepMindが公開した、MuJoCo物理シミュレータ上でMPCをリアルタイム実行するフレームワークです。人型ロボットや四足歩行ロボットの動作をMPCで制御するデモが含まれており、現代制御の最先端を体験できます。[MuJoCo MPC GitHub](https://github.com/google-deepmind/mujoco_mpc)

__Quadruped-PyMPC__

四足歩行ロボット向けのPython製MPCフレームワークです。単一剛体モデルに基づき、勾配ベース（acados）またはサンプリングベース（JAX）のMPCをMuJoCo上で実行できます。[Quadruped-PyMPC](https://github.com/iit-DLSLab/Quadruped-PyMPC)

__balance_robot_algorithm__

ROS/Gazebo上で動作する自平衡ロボットシミュレータで、LQRとMPCの両方を比較実装しています。ROS環境があれば、実際のロボットに近い形で現代制御を体験できます。[balance_robot_algorithm](https://github.com/66Lau/balance_robot_algorithm)

### 4. 教育用リポジトリ・Jupyter Notebook

__control-playground (二重倒立振子)__

PID、極配置、LQR、iLQR、線形MPC、非線形MPCを二重倒立振子で比較するJupyter Notebookです。各制御理論の違いを同じ問題設定で体験できる貴重な教材です。[control-playground](https://github.com/kosuke55/control-playground)

__Controllers from PID to QP-MPC__

PIDからQP-MPCまでの制御器を対話的に可視化するPythonデモとHTMLエクスプローラが含まれています。ゼロ点が2次系のステップ応答に与える影響などをインタラクティブに学べます。[Controllers-from-PID-to-QP_MPC](https://github.com/TonyInvent/Controllers-from-PID-to-QP_MPC)

## 総括

制御とは、**「不確実な現実を、望ましい目標に近づけ続ける技術」** です。

センサで測った「今の状態」と「目標の状態」の差を見て、アクチュエータに適切な力を与える。この一見単純なループの中に、古典制御と現代制御の2つの思想があります。

**古典制御（PIDなど）** は、入出力の関係から経験的にシステムを整える手法です。実装が容易で現場の調整ノウハウも豊富なため、単軸のモータ制御など多くの場面で今も第一選択です。

**現代制御（LQR・MPCなど）** は、システムの内部状態（位置・速度など）を直接扱う状態空間表現に基づきます。複数の状態を同時に最適化したり、物理的な制約を明示的に考慮したりできるため、倒立振子や二足歩行ロボットといった複雑なシステムで真価を発揮します。

要するに、制御とは**「モデルと現実の差を埋めながら、目的を達成し続ける営み」**です。古典制御も現代制御も、その目的は同じです。違うのは、対象の複雑さに対してどのような言語で記述し、どのように最適な操作量を導出するかという点だけです。
