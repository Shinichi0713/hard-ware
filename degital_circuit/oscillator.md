NORゲートだけを使ったクロック発振器（パルス発生回路）は、**NORゲートをインバータ（NOTゲート）として利用し、RC（抵抗＋コンデンサ）回路と組み合わせる**ことで実現できます。  
以下に、代表的な構成例を説明します。

---

## 基本構成

### 1. 構成要素

- NORゲート（2入力）×2個
- 抵抗（R）×1本
- コンデンサ（C）×1個

### 2. 回路図イメージ

```
      +----[ R ]----+
      |             |
     [ ]           [ ]
     NOR1         NOR2
      |             |
      +----||-------+
           C
```

### 3. 接続方法

1. **NOR1の2つの入力端子をショート（同じ信号を入れる）**  
   → こうするとNORゲートは「NOTゲート」として動作します（NOR( A, A ) = NOT A）。

2. **NOR1の出力をNOR2の片方の入力へ接続**  
   → NOR2は「バッファ」や「インバータ」として使うこともできます。

3. **抵抗RをNOR1の出力とNOR1の入力の間に挿入**  
   → NOR1の入力（＝NOR2の出力）と出力の間にRを入れる。

4. **コンデンサCをNOR1の入力とGNDの間に接続**  
   → NOR1の入力とGNDをCで接続。

### 4. 動作原理

- 抵抗RとコンデンサCの充放電によって、NOR1の入力電圧がゆっくり変化します。
- NOR1がインバータとして働き、出力が一定しきい値を超えると反転。
- これが繰り返され、**一定周期のパルス（クロック信号）**が出力されます。

---

## 回路図（簡易図）

```
   +Vcc
    |
   [R]
    |
   +-------+
   |       |
  ---     [NOR1]----+
  ---C    (入力A,B) |
   | \    (A,Bを短絡)|
   |  \             |
   |   +------[NOR2]----- 出力（クロック）
   |                |
  GND              GND
```

---

## ポイント

- **NORゲートをNOTゲートとして使う**のがコツです。
- 抵抗RとコンデンサCの値によって発振周期（クロックの速さ）が決まります。
- シンプルな発振回路ですが、**デジタルICだけで発振器が作れる**点が面白いポイントです。
