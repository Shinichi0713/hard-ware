# 整流回路

「整流回路」は電気・電子機器の中でとても身近に使われていて、実は私たちが毎日使うほとんどの機器の中に入っています。

# ✅ 整流回路とは

交流（AC）を直流（DC）に変換する回路のこと。

基本的には「ダイオード」を使って一方向の電流だけを通すことで実現します。

（半波整流・全波整流・ブリッジ整流などがある）

# ✅ 整流回路の使われ方（具体例）

1. **ACアダプタや充電器**
   * 家庭用100V（AC） → 整流 → DC化 → スマホやPCへ供給
   * ブリッジ整流＋平滑コンデンサが必ず入っている
2. **スイッチング電源**
   * ACを一度DCに整流してから、高周波に変換して効率的に電圧を変換
   * PC電源やテレビなどの内部
3. **オーディオ機器**
   * アンプの電源部でACをDCに変換
   * リップルが音に乗らないよう、大容量コンデンサやレギュレータと併用
4. **家電製品**
   * 電子レンジ、冷蔵庫、エアコンなどの制御回路用電源
   * モータ制御回路の直流バス電源として
5. **太陽光発電・風力発電**
   * 逆に、発電機からの交流を整流して直流化し、バッテリやインバータに送る
6. **溶接機や工業用機器**
   * 溶接に使う直流電源を作るために交流を整流して利用
7. **自動車**
   * オルタネータ（発電機）は交流を出力するが、整流回路で直流にしてバッテリに充電

# ✅ まとめ

整流回路は **「交流を直流に変換する」＝ほぼすべての電子機器の電源部に必須** です。

* 家電やスマホの充電器
* パソコンやオーディオ機器
* 車や発電システム

など、**電源があるところには必ず整流回路がある**といっても過言ではありません。
