# 構成

LTspice で **LC回路（共振回路やフィルタ回路）** を再現するのはとても基本的で、シミュレーションの勉強に最適です。以下に手順と構成例をまとめますね。

---

## ✅ 1. 基本的なLC共振回路（直列型）

* 電源（AC電源） → インダクタ L → コンデンサ C → グラウンド
* 特定の周波数 f0=12πLCf_0 = \frac{1}{2\pi\sqrt{LC}} で共振して、インピーダンスが最小になる

**LTspiceでの構成例**

```
Vin N1 0 AC 1         ; AC電源 (振幅1V)
L1 N1 N2 10m          ; インダクタ 10mH
C1 N2 0 100n          ; コンデンサ 100nF
Rload N2 0 1k         ; 負荷抵抗 1kΩ
.ac dec 100 10 1Meg   ; 10Hz～1MHzを周波数解析
.plot ac V(N2)
```

---

## ✅ 2. 並列共振回路

* 電源に対して L と C を並列につなぐ
* 共振周波数ではインピーダンスが最大になり、ほとんど電流が流れなくなる

**LTspiceでの構成例**

```
Vin N1 0 AC 1
L1 N1 N2 10m
C1 N2 0 100n
Rload N1 N2 1k
.ac dec 100 10 1Meg
.plot ac I(Vin)
```

---

## ✅ 3. フィルタ回路への応用

* **ローパスフィルタ** ：Lを直列に、CをGNDに接続
* **ハイパスフィルタ** ：Cを直列に、LをGNDに接続
* **バンドパス**や**バンドストップ**はLとCの組み合わせで実現

---

## ✅ LTspice での操作の流れ

1. **新しい回路図を作成**
   * `File > New Schematic`
2. **部品の配置**
   * `F2`キーで部品一覧を開き、`inductor`, `capacitor`, `resistor`, `voltage source` を配置
3. **電源設定**
   * 電圧源を右クリック → 「AC Amplitude = 1」などを設定
4. **解析コマンド**
   * `.ac dec 100 10 1Meg` を追加（周波数解析）
   * `.tran 0 10m` などで過渡解析も可能
5. **シミュレーション実行**
   * 実行ボタン ▶ を押すと波形ビューアに結果が出る

---

## ✅ まとめ

* **直列LC** ：共振で電流が大きくなる（バンドパス的）
* **並列LC** ：共振で電流が小さくなる（バンドストップ的）
* **応用** ：LとCの接続方法を変えてフィルタや発振器を作れる
