# クロック生成

「クロックを生成する回路」というのは、**一定周期でON/OFFが繰り返される信号（矩形波）を作る回路**のことですね。

---

# ✅ クロック生成回路の代表的な方法

## 1. **RC発振回路（アナログ方式）**

* 抵抗 RR とコンデンサ CC の充放電を利用して発振する
* **例** ：
* **アスタブルマルチバイブレータ** （トランジスタやオペアンプで構成）
* NE555タイマIC（有名なクロック生成IC）

👉 周期は T≈k⋅RCT \approx k \cdot RC で決まる（kkは回路定数による係数）。

👉 簡単にクロックを作れるが、精度はあまり高くない。

---

## 2. **水晶発振回路（クリスタルオシレータ）**

* **水晶振動子（Quartz Crystal）**を利用して、非常に安定した発振を得る
* インバータICやトランジスタと組み合わせて発振回路を構成する
* PCやFPGA、マイコンに入っている「クロック源」はほとんどこれ

👉 周波数精度が非常に高い（ppmレベル）

👉 代表例：32.768kHz（水晶時計用）、10MHz（通信機器用）、50MHz/100MHz（FPGA用）

---

## 3. **PLL（Phase-Locked Loop）回路**

* ある基準クロックから、周波数を整数倍/分周して別のクロックを作る
* FPGAやマイコン内部でよく使われる
* **例** ：50MHz入力 → PLL → 200MHzクロック生成

👉 周波数を柔軟に変えられるが、外部基準クロック（水晶発振器）が必要

---

## 4. **リングオシレータ**

* NOTゲート（インバータ）を奇数個直列につなぎ、出力を入力にフィードバックする
* 信号がぐるぐる回り続けて発振する
* FPGA内部で簡易クロックを作るときに使われるが、周波数は不安定

---

# ✅ 実用例

* **Arduinoのクロック** → 外部16MHz水晶発振器
* **FPGA** → 外部50MHzオシレータ + 内部PLLで変換
* **安価なタイマー** → RC発振回路
* **時計** → 32.768kHz水晶振動子

---

# ✅ まとめ

* **RC発振回路** → 簡単だけど精度低い
* **水晶発振器** → 精度が高く、マイコン・FPGAで必須
* **PLL** → 基準クロックを元に周波数変換
* **リングオシレータ** → 簡易クロック、実験用

---




それでは **NE555タイマICを使ったクロック生成回路** を説明します。

NE555は定番のタイマICで、**発振回路（アスタブル動作）**を簡単に作れるので、入門にもってこいです。

---

# ✅ NE555を使ったクロック発振回路（アスタブルモード）

## 📌 回路図イメージ

```
 Vcc (+5V)
   |
   |
  [R1]
   |
   +--------+
   |        |
  [R2]     (7) Discharge
   |        |
  [C]------(6) Threshold
   |        |
  GND      (2) Trigger
             |
            (3) Output → クロック信号
```

* **R1, R2** ：抵抗
* **C** ：コンデンサ

👉 この組み合わせでコンデンサの充放電を繰り返し、出力が「HIGH/LOW」と交互に切り替わります。

---

## 📌 動作原理

1. コンデンサCがR1とR2を通して充電される → 出力 HIGH
2. 一定電圧に達すると、555内部コンパレータが動作し、放電トランジスタON → 出力 LOW
3. R2を通してコンデンサが放電 → 再び閾値以下になったら出力 HIGH
4. 1〜3を繰り返して、矩形波（クロック）が得られる

---

## 📌 発振周期（クロック周期）

NE555のアスタブルモードでは、周期Tは次の式で表されます：

T=0.693⋅(R1+2R2)⋅CT = 0.693 \cdot (R1 + 2R2) \cdot C
周波数はその逆数：

f=1T=1.44(R1+2R2)⋅Cf = \frac{1}{T} = \frac{1.44}{(R1 + 2R2) \cdot C}

* デューティ比（ON/OFFの比率）は R1R1 と R2R2 の組み合わせで決まります。

---

## 📌 例

* R1 = 1kΩ, R2 = 10kΩ, C = 10µF

T≈0.693⋅(1k+20k)⋅10µ=0.693⋅21k⋅10µ≈0.145sT \approx 0.693 \cdot (1k + 20k) \cdot 10µ
   = 0.693 \cdot 21k \cdot 10µ
   ≈ 0.145 s
f≈6.9Hzf \approx 6.9 Hz
👉 約7Hzのクロック（ON/OFFを繰り返す矩形波）が得られる。

---

## 📌 応用例

* LEDの点滅（低周波数のクロック）
* マイコンやFPGAの外部クロック源（高周波で設計）
* 矩形波を基準にしたブザー駆動

---

# ✅ まとめ

* NE555をアスタブルモードで使うと「R1・R2・C」で決まる周期のクロックが生成できる
* 周期 T=0.693(R1+2R2)CT = 0.693 (R1 + 2R2)C
* 周波数は f=1.44/((R1+2R2)C)f = 1.44 / ((R1 + 2R2)C)
