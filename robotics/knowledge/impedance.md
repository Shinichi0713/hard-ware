# インピーダンス

「インピーダンス」は、直流の「抵抗」を交流に拡張した概念です。

---

# ✅ インピーダンスとは

* **交流回路における“電気の流れにくさ”を表す量**
* 抵抗（R）だけでなく、コイル（L）やコンデンサ（C）の周波数依存の性質も含めて表す
* 記号：ZZ
* 単位：オーム（Ω）

交流回路における電流の流れにくさ。

---

# ✅ 数学的な定義

インピーダンス ZZ は **複素数** で表されます：

Z=R+jXZ = R + jX

* RR：抵抗成分（実数部分）
* XX：リアクタンス（虚数部分）
  * インダクタのリアクタンス： XL=ωL=2πfLX_L = \omega L = 2\pi f L
  * コンデンサのリアクタンス： XC=−1ωC=−12πfCX_C = -\frac{1}{\omega C} = -\frac{1}{2\pi f C}

👉 **抵抗は周波数に依存しないが、LやCは周波数によって値が変わる**

> インピーダンスは複素数で決められる。

---

# ✅ 直感的なイメージ

* **抵抗 R** ：水道管の太さに相当 → 常に流れにくさ一定
* **インダクタ L** ：水の流れの変化を妨げる慣性 → 高速な変化（高周波）を流しにくい
* **コンデンサ C** ：流れをためるバネのような性質 → 低速な変化（低周波）を流しにくい

---

# ✅ インピーダンスの応用例

1. **フィルタ設計**
   * LやCのインピーダンス特性を利用して、特定周波数を通す/遮断する
2. **インピーダンス整合**
   * アンテナやオーディオ回路で、信号源と負荷のインピーダンスを合わせると効率的に電力伝送できる
3. **共振回路**
   * LC回路でインピーダンスが最小/最大になる周波数を利用（同調・発振）

---

# ✅ まとめ

* インピーダンス = 交流における「抵抗」
* 抵抗 R に加え、コイルやコンデンサの性質（リアクタンス X）も含む
* 周波数に依存して変化する
* 信号伝送・フィルタ・アンテナ・電源設計などで重要
