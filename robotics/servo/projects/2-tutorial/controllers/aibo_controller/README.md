Aibo（ERS-1000など）のような4足歩行ロボットには、e-puckよりも高度で多様なセンサーが搭載されています。Webots上のAiboモデル（または実機に近いシミュレーション）で、センサーを活用して「生命感」を出すための代表的な実装例をいくつか紹介します。

Aiboには **接触センサー（Touch Sensor）** 、 **TOF（距離）センサー** 、 **カメラ** 、**加速度計**などが備わっていることを前提としています。

---

### 1. タッチセンサーによる「なでなで」への反応

Aiboの頭部や背中にはタッチセンサーがあります。これを使って、撫でられたら「喜ぶ（尻尾を振る、頭を上げる）」という動作を実装します。

* **使用センサー:** `TouchSensor` (head, back)
* **仕組み:** センサー値が `1.0`（接触あり）になったら、特定のモーション（尻尾のサーボを高速で振るなど）を開始します。
* **応用:** 撫でる時間の長さに応じて、喜びの度合いを変えるロジック。

### 2. TOFセンサーによる「お手」や「衝突回避」

鼻先や腰にあるTOF（Time of Flight）センサーは、非常に正確な距離を測定できます。

* **使用センサー:** `DistanceSensor` (ToF)
* **例1（お手）:** Aiboの鼻先に手をかざすと（距離が10cm以下になると）、前足を上げて「お手」のポーズをとる。
* **例2（崖っぷち検知）:** 前足の裏にあるセンサーが床との距離を測定し、急に距離が離れたら「段差がある」と判断して後退する。

### 3. 加速度計・ジャイロを使った「転倒復帰」

ロボットが転んだときに、自分の姿勢を認識して自力で起き上がるアルゴリズムです。

* **使用センサー:** `Accelerometer`, `Gyro`
* **仕組み:** - 重力ベクトル（**$Z$**軸の向き）を計算し、背中が下を向いているか、横を向いているかを判定します。
  * 仰向け（**$Z$**軸が逆転）であれば、足をバタつかせて反動で起き上がる特定の「起き上がりモーション」をトリガーします。

### 4. カメラによる「ピンクのボール」の追跡

Aiboの鼻先カメラを使って、特定の色の物体（公式のピンクボールなど）を追いかけるプログラムです。

* **使用センサー:** `Camera`
* **仕組み:**
  * カメラ画像から「ピンク色」のピクセルを抽出。
  * 画面内のピンク色の中心座標（重心）を計算。
  * 中心が画面の右寄りにあれば右旋回、左寄りにあれば左旋回、中心なら前進する。

### 5. 音声センサー（マイク）による「拍手」への反応

Webotsの `Microphone` デバイスを使って、特定の音量を超えたら反応させます。

* **使用センサー:** `Microphone`
* **仕組み:** 音の強さ（RMS値など）を取得し、一定以上のピーク（パチンという拍手音）を検知したら、ワンと鳴く（または特定の動作をする）。

### 実装のアドバイス：Aiboのデバイス名確認

WebotsでAiboを扱う際、デバイス名はメーカー独自の形式（例：`PRM:/r1/c1-Joint2:11` など）になっていることが多いです。

前にお伝えした**「デバイス名一覧を取得するコード」**を使って、まずはあなたの環境のAiboにどんな名前のセンサーが付いているか確認することをおすすめします。

**Python**

```
# Aiboの特定のセンサーを有効化する例
head_touch = robot.getDevice('head touch sensor') # 名前は環境により異なります
if head_touch:
    head_touch.enable(timestep)
```

**この中で、実際にコードとして書いてみたい（実装してみたい）具体的な動作はありますか？**

例えば「カメラで色を追いかける」や「倒れたら起き上がる」など、興味があるものを教えていただければサンプルコードを作成します。
