## デバイス一覧
e-puckに搭載されているデバイスは、名前だけでは役割がわかりにくいものがいくつかあります。ご質問のデバイス名（リスト）が提示されていなかったため、Webotsのe-puckモデルに標準で搭載されている主要なデバイスについて、その意味と役割をまとめました。

もし、これら以外の特定の名称について知りたい場合は、続けて教えてください。

### e-puck デバイス一覧表

| デバイス名 | デバイスの種類 | 意味・役割 |
| --- | --- | --- |
| **`left wheel motor`** | Motor | **左車輪用モーター**。左側のタイヤを回転させます。 |
| **`right wheel motor`** | Motor | **右車輪用モーター**。右側のタイヤを回転させます。 |
| **`ps0` 〜 `ps7**` | DistanceSensor | **近接センサー（8個）**。赤外線で周囲の障害物との距離を測ります（0が前方、時計回りに配置）。 |
| **`ls0` 〜 `ls7**` | LightSensor | **光センサー（8個）**。周囲の光の強さを測定します。近接センサーと同じ場所に配置されています。 |
| **`gs0`, `gs1`, `gs2**` | DistanceSensor | **グラウンド（床面）センサー**。底面にあり、床の色や線を検知します（ライントレース用）。 |
| **`led0` 〜 `led9**` | LED | **LEDライト**。本体の周りや上部にあるLEDを点灯・消灯させます。 |
| **`camera`** | Camera | **カメラ**。前方の画像を取得します。標準解像度は低め（52x52など）に設定されています。 |
| **`accelerometer`** | Accelerometer | **加速度計**。3軸の加速度（重力や衝撃）を測定し、ロボットの傾きなどを知ることができます。 |
| **`gyro`** | Gyro | **ジャイロセンサー**。ロボットの角速度（回転する速さ）を測定します。 |
| **`left wheel sensor`** | PositionSensor | **左車輪エンコーダ**。左タイヤがどれくらい回転したか（角度）を測定します。 |
| **`right wheel sensor`** | PositionSensor | **右車輪エンコーダ**。右タイヤがどれくらい回転したか（角度）を測定します。 |
| **`microphone`** | Microphone | **マイク**。周囲の音を検知します（Webotsのスピーカーデバイスと組み合わせて使用）。 |

### デバイス名の規則

* **ps** = **P**roximity **S**ensor（近接センサー）
* **ls** = **L**ight **S**ensor（光センサー）
* **gs** = **G**round **S**ensor（床面センサー）

特に `ps0` 〜 `ps7` は、ロボットの真前から時計回りに番号が振られています（`ps0`と`ps7`が前方、`ps3`と`ps4`が後方）。障害物回避プログラムを作る際は、この番号の配置を意識するのがコツです。



## センサの応用例

e-puckは小型ながら非常に完成度が高く、大学の研究や教育現場で「自律分散ロボット」や「群ロボット（Swarm Robotics）」の実験によく使われます。

近接センサー（`ps`）、床下センサー（`gs`）、カメラ、加速度計などを組み合わせた応用例をいくつか紹介します。

---

### 1. ライントレース (Line Following)

底面にある3つの床下センサー（`gs0`, `gs1`, `gs2`）を使用して、地面に描かれた黒い線を辿る制御です。

* **使用センサー**: `DistanceSensor` (gs0, gs1, gs2)
* **制御内容**:
* 中央のセンサーが黒（低い値）を検知していれば前進。
* 右のセンサーが黒を検知したら右に修正、左なら左に修正。


* **応用**: 配送ロボットの基礎となる技術です。PID制御を組み合わせることで、滑らかに線を辿ることができます。

### 2. 崖っぷち回避 (Cliff Detection)

床下センサー（`gs`）を使って、テーブルの端や段差から落ちないようにする制御です。

* **使用センサー**: `DistanceSensor` (gs0, gs1, gs2)
* **制御内容**:
* 通常の床（反射あり）から、床がない（反射なし＝極端に高い値または低い値）状態への変化を検知します。
* 崖を検知した瞬間に急停止し、後退してから方向転換します。


* **応用**: お掃除ロボット（ルンバなど）に必ず搭載されている安全機能です。

### 3. 向光性・背光性 (Light Following / Hiding)

8つの光センサー（`ls0` 〜 `ls7`）を使って、光源を探したり、逆に暗い場所に隠れたりする制御です。

* **使用センサー**: `LightSensor` (ls0 〜 ls7)
* **制御内容**:
* **向光性**: 最も強い光を検知しているセンサーの方向に回転して進む（虫が街灯に集まるような動き）。
* **背光性**: 光から逃げて影を探す（ゴキブリのような動き）。


* **応用**: 太陽光パネルを常に太陽に向ける制御や、自動充電ステーションを探す際に使われます。

### 4. 協調走行・追従走行 (Leader-Follower)

複数台のe-puckを使い、前のロボットの後ろを一定距離で追いかける制御です。

* **使用センサー**: `DistanceSensor` (ps) + `Camera`
* **制御内容**:
* 前方のロボットをカメラの色認識で捉える、あるいは近接センサーで一定の距離（ターゲット値）を保つようにPID制御を行います。


* **応用**: 自動運転車の「隊列走行」のシミュレーションに使われます。

### 5. 迷路探索 (Maze Solving / Wall Following)

近接センサーを使って壁との距離を測りながら、未知の迷路を脱出するアルゴリズムです。

* **使用センサー**: `DistanceSensor` (ps0 〜 ps7)
* **制御内容**:
* **右手法（Right Hand Rule）**: 常に右側の壁に沿って進むようにPID制御を行い、突き当たりでは左に曲がることで、必ず出口に到達します。


* **応用**: マイクロマウス競技などで使われる、迷路解析の基礎です。

### 6. 加速度計による衝撃・転倒検知

* **使用センサー**: `Accelerometer`
* **制御内容**:
* 急激な加速度の変化（衝撃）を検知して停止する、あるいはロボットがひっくり返ったことを検知してエラーを出す。


* **応用**: ロボットの故障防止や、緊急停止システムの構築に役立ちます。

---

### 実装のヒント

これらの応用例を作る際は、以下のステップで進めるのがスムーズです。

* **ステップ1**: まず個別のセンサー値を `print` して、壁がある時とない時で数値がどう変わるか確認する。
* **ステップ2**: `if` 文による単純な条件分岐で動かしてみる。
* **ステップ3**: 動きを滑らかにするために「Braitenberg法」や「PID制御」を取り入れる。

**次は、これらのどれかを実際にPythonコードで実装してみますか？**
例えば「ライントレース」や「光を追いかける」などは、Webotsの標準ワールドですぐに実験できます。


## センサの特性

e-puckに搭載されている**ps（近接センサー）**と**ls（光センサー）**は、物理的な配置は同じですが、値の変化の仕方が**「正反対」**に近い特性を持っています。

それぞれのセンサーが、対象物（壁や光）に**近い時**と**遠い時**でどのような値をとるか、表にまとめました。

---

### psセンサーとlsセンサーの値の変化

| センサー種類 | 対象物 | **近い時 (Close)** | **遠い時 (Far)** | 特徴 |
| --- | --- | --- | --- | --- |
| **ps (Proximity)** | 壁・障害物 | **大きな値** (最大 4096) | **小さな値** (0 に近い) | 物に近づくほど数値が上昇します。 |
| **ls (Light)** | 光源 (ランプ) | **小さな値** (0 に近い) | **大きな値** (最大 4000) | 明るいほど数値が減少し、暗いほど上昇します。 |

---

### 詳細な解説

#### 1. psセンサー (近接センサー)

赤外線を出して、跳ね返ってきた量を測定しています。

* **近い時:** 赤外線がたくさん跳ね返ってくるため、値が**大きく**なります（例: 壁の直前で 1000〜3000）。
* **遠い時:** 反射光が届かないため、値は **0** に近くなります。
* **注意点:** 黒い壁など、赤外線を吸収する色の物体には反応しにくい（値が大きくならない）ことがあります。

#### 2. lsセンサー (光センサー)

周囲の明るさを測定しています。実機の電子回路の仕組みを模しているため、直感とは逆の動きをします。

* **近い時（明るい）:** 強い光を受けると、抵抗値が下がるような挙動を見せ、値は **0** に近づきます。
* **遠い時（暗い）:** 光が当たらない「真っ暗」な状態では、値は最大（約 **4000** 程度）まで上昇します。
* **注意点:** Webotsのワールド内に「Light（光源）」が設置されていないと、常に大きな値（暗い状態）のままになります。

---

### 実装時の使い分けアドバイス

プログラムを書く際は、以下のようなイメージで条件分岐を作るとスムーズです。

* **障害物回避 (ps使用)**
* `if ps_value > 100:` → 「壁が**近い**！避けろ！」


* **光を追いかける (ls使用)**
* `if ls_value < 500:` → 「ここが一番**明るい**！ここに止まろう」
