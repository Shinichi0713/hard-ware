Braitenberg法のような「反射的（リアクティブ）」な制御以外にも、現代のロボット工学で使われる高度な制御手法がいくつかあります。e-puckはシンプルですが、それゆえに多様なアルゴリズムの実験台として最適です。

主要な制御手法を4つのカテゴリに分けて紹介します。

---

### 1. PID制御 (比例・積分・微分制御)

特定の「目標値」に正確に合わせるための、最もポピュラーな古典制御手法です。

* **使い方:** 「壁から常に5cmの距離を保って走る（壁沿い走行）」や「指定した速度を正確に維持する」際に使われます。
* **仕組み:** 目標値と現在の値の「差（エラー）」を計算し、その差を埋めるようにモーター出力を調整します。
* **メリット:** 非常に安定しており、行き過ぎ（オーバーシュート）やガタつきを抑えられます。

### 2. SLAM と ナビゲーション (地図作成と自己位置推定)

ロボットが自分の場所を知り、目的地までの最短ルートを計算する手法です。

* **使い方:** 迷路の脱出や、部屋の掃除ロボットのような動き。
* **仕組み:** `accelerometer`（加速度）や車輪のエンコーダを使って自分の移動量を計算し（オドメトリ）、同時に距離センサーで壁の形を記録して地図を作ります。
* **メリット:** 未知の環境でも、最短距離でゴールへ向かう「かしこい」動きが可能です。

### 3. ニューラルネットワークと強化学習 (AI)

「どう動くべきか」を人間が教えるのではなく、ロボットが自分で学習する手法です。

* **使い方:** 複雑な障害物コースの走破や、複数台のe-puckによる協調作業。
* **仕組み:** 「壁にぶつかったらマイナス、進めたらプラス」という報酬を与え、シミュレーション内で何万回も試行錯誤（学習）させます。
* **メリット:** 人間が思いつかないような効率的（あるいは奇妙な）回避パターンを見つけ出すことがあります。

### 4. 状態遷移マシン (FSM: Finite State Machine)

「モード（状態）」を切り替えて動かす手法です。

* **使い方:** 「普段は探索モード」→「壁を見つけたら回避モード」→「光を見つけたら追跡モード」といった複雑なタスク。
* **仕組み:** 下記のような状態の図を作成し、特定の条件（センサー値など）でモードを切り替えます。
* **メリット:** ロジックが整理され、大規模なプログラムでも管理しやすくなります。

---

### 比較表：どの手法を選ぶべき？

| **手法**           | **難易度** | **特徴** | **e-puckでの主な用途** |
| ------------------------ | ---------------- | -------------- | ---------------------------- |
| **Braitenberg**    | 低               | 反射的、生物的 | シンプルな障害物回避         |
| **PID制御**        | 中               | 数学的、正確   | 壁沿い走行、速度維持         |
| **FSM (状態遷移)** | 中               | 論理的、多機能 | 迷路探索、ゴミ拾いタスク     |
| **SLAM / AI**      | 高               | 知能的、学習   | 自律走行、高度な地図作成     |

**次は、これらのうちどれかを実際にプログラミングしてみますか？**

例えば、**「PID制御を使った壁沿い走行（Wall Following）」**は、e-puckの練習として非常に人気があり、数学的な面白さも味わえるのでおすすめです。
