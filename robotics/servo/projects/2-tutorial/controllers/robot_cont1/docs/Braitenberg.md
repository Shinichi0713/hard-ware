Braitenberg法（ブライテンベルグ・ビークル）とは、イタリアの神経科学者ヴァレンティーノ・ブライテンベルグが提唱した、**「非常に単純な仕組みで、あたかも知能や感情を持っているかのように振る舞うロボット（ビークル）」**の思考実験、およびその制御手法のことです。

複雑な計算や「壁を避けよう」という高度なプログラミングを一切行わず、**「センサーの値」をそのまま「モーターの速度」に直結させる**のが最大の特徴です。


### 1. 基本的な考え方

通常のプログラミングが「もし壁があったら（IF）、止まる（THEN）」という**論理判断**であるのに対し、Braitenberg法は**「センサーが強く反応したら、繋がっているモーターを速く回す」**という物理的な接続のみを考えます。

この接続の仕方（「真っ直ぐ繋ぐ」か「交差して繋ぐ」か）によって、ロボットに「性格」が生まれます。

### 2. 代表的な「性格」の例

| 接続パターン | 動きの名称 | ロボットの振る舞い（性格） |
| --- | --- | --- |
| **並行（直線）** | **臆病 (Coward)** | 障害物がある方のタイヤが加速するため、障害物から**逃げるように**離れていきます。 |
| **交差（クロス）** | **攻撃的 (Aggressive)** | 障害物がある側の反対のタイヤが加速するため、障害物へ**突っ込んでいきます**。 |
| **並行（反転）** | **好奇心 (Curious)** | 遠くに何かを見つけると近づきますが、近づきすぎると速度を落として様子を伺います。 |
| **交差（反転）** | **愛 (Love)** | 好きなもの（光など）を見つけると、その前でピタッと止まり、離れません。 |

> **注釈：** 「反転」とは、センサー値が強いほど速度を下げる（抑制する）接続のことです。



### 3. e-puckでの実装例（スムーズな障害物回避）

先ほどのe-puckのコードを、このBraitenberg法（臆病タイプ）に書き換えると、驚くほど滑らかに動くようになります。

```python
# 左右のモーターにかける重み（係数）の行列
# 近接センサー ps0〜ps7 の値にこれらの値を掛けて速度を決めます
weights_left  = [150, 100, 80, -10, -10, -20, -30, -50]
weights_right = [-50, -30, -20, -10, -10, 80, 100, 150]

base_speed = 3.0

while robot.step(timestep) != -1:
    ps_values = [s.getValue() for s in sensors]
    
    # 基本速度に、各センサーの反応 × 重みを加算する
    left_speed = base_speed
    right_speed = base_speed
    
    for i in range(8):
        # センサー値を正規化して重みを掛ける
        # 障害物が近いほど、反対側の車輪を加速させ、同じ側を減速させる
        left_speed  += (ps_values[i] / 4096.0) * weights_left[i]
        right_speed += (ps_values[i] / 4096.0) * weights_right[i]
    
    left_motor.setVelocity(left_speed)
    right_motor.setVelocity(right_speed)

```

### 4. なぜこの手法がすごいのか？

* **計算が軽い:** 複雑な条件分岐（if文の連発）が不要で、掛け算と足し算だけで動きます。
* **生物的でスムーズ:** カクカクした動きではなく、障害物に合わせて無段階にカーブを曲がる、まるで生き物のような動きになります。
* **創発性:** 非常に単純なルールから、「複雑で賢そうな振る舞い」が自然に生まれます。

この手法は、自律走行ロボットの基礎中の基礎であり、現代のAIやロボット工学においても「ボトムアップ型」の知能を考える上で非常に重要な概念です。
