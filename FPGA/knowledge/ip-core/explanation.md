# IPコアの学習前知識

## IPコアとは
ICやFPGAなどのハードウェア設計において再利用可能な回路設計のことを示す。
設計資産なのでIPコア。

- IPコアは特定の機能を持つ回路ブロックを設計データとしてまとめたもの
- イーサネットコントローラや、よく使われる機能をIPコアとして提供している。
- 半導体メーカや設計会社はこれらのIPコアを組み合わせて大規模なLSIやFPGA設計を効率よく行う

## IPコアの種類
### ソフトIPコア

RTL（VHDLやVerilogなど）で記述された設計データ
利用者が自分の環境や用途に合わせて合成・最適化できる
### ハードIPコア

物理設計まで完了しているデータ（レイアウト済みの回路など）
特定のプロセスやデバイス向けに最適化されている
### ファームIPコア

ソフトIPとハードIPの中間的なもの

## 利用例
- FPGA設計で、Ethernet通信機能を追加したい場合、Ethernet MACのIPコアを導入することで、ゼロから設計せずに機能を実現できる。
- スマートフォンのSoC（System on Chip）には、CPUやGPU、各種インターフェース（USB、HDMIなど）のIPコアが組み合わされている。

## メリット
- 設計の効率化・短期間化：よく使われる機能を再利用できる
- 品質の向上：実績あるIPコアを使うことで信頼性が高まる
- コスト削減：開発工数やリスクを減らせる

## この JTAG を使って動作中の FPGA 内部のレジスタの値を読み書きする機能を提供するIPコアが VIO (Virtual Input/Output)

**VIO（Virtual Input/Output）IPコアとは、JTAGインターフェースを利用して、動作中のFPGA内部のレジスタや信号の値を外部PCからリアルタイムで読み書きできるデバッグ用IPコア**です。これにより、FPGAの設計や動作確認が効率的に行えるようになります。

### 詳しい解説

#### 1. JTAGとは？
- JTAG（Joint Test Action Group）は、主にICのテストやデバッグ、プログラミングに使われるインターフェース規格です。
- FPGAでは、プログラム書き込みやデバッグ、内部信号の観測などに利用されます。

#### 2. VIO（Virtual Input/Output）IPコアとは？
- VIOは、FPGAベンダ（例：XilinxやIntel/Altera）が提供する**デバッグ用のIPコア**です。
- **JTAG経由でFPGA内部のレジスタや信号値を外部PCから観測したり、逆に外部から値を書き込んでFPGA内部の動作を制御したりできる**機能を持ちます。

#### 3. どういうことか？
- 通常、FPGAの内部信号やレジスタは、動作中に外部から直接観測・制御することはできません。
- しかし、VIO IPコアをFPGAに組み込むと、**JTAGケーブルを通じてPC上のツール（例：Xilinx Vivadoのハードウェアマネージャ）の画面から、FPGA内部の信号値をリアルタイムで見たり、任意の値を書き込んで動作を変えたりできる**ようになります。
- つまり、**「仮想的なI/Oポート」として、FPGAの内部と外部（PC）をつなぐブリッジの役割**を果たします。

#### 4. 何が便利か？
- デバッグや評価時に、FPGAの設計を変更せずに内部状態を確認できる
- 外部から値を書き込んで、回路の動作をその場で変化させてテストできる
- 実際のI/Oピンを消費せずに、仮想的なI/Oとして使える
