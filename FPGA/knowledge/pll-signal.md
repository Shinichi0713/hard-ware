# PLLの用途


PLL（Phase-Locked Loop：位相同期ループ）は、入力信号の位相に同期した出力信号を生成する回路です。以下のような用途で広く使用されています：

## **1. 周波数合成**

* **クロック生成** : CPUやデジタル回路のクロック信号生成
* **周波数逓倍** : 基準周波数から高い周波数を生成
* **周波数分周** : 高い周波数から低い周波数を生成

## **2. 通信システム**

* **キャリア復調** : AM/FM/PSK信号の復調
* **クロック・データ復元** : デジタル通信での同期
* **周波数シンセサイザ** : 無線機の周波数切り替え

## **3. デジタル回路**

* **クロック分配** : システム全体の同期クロック供給
* **ジッタ除去** : クロック信号のノイズ除去
* **スキュー調整** : 信号タイミングの調整

## **4. 測定・制御**

* **周波数測定** : 入力信号の周波数測定
* **位相差測定** : 2つの信号間の位相差測定
* **モータ制御** : 回転数制御、位置制御

## **5. 音響・映像機器**

* **ワウフラッタ除去** : 録音・再生機器のスピード制御
* **同期信号生成** : ビデオ機器の水平・垂直同期
* **音声処理** : デジタルオーディオのサンプリングクロック

## **6. 具体的な応用例**

* **CPU** : 外部クロックから内部高速クロック生成
* **無線LAN** : 送受信周波数の同期
* **GPS受信機** : 衛星信号との同期
* **ハードディスク** : データ読み書きの同期
* **液晶ディスプレイ** : 画素クロックの生成

PLLは現代の電子機器において、正確なタイミング制御や周波数制御を行うための基本的で重要な技術です。
