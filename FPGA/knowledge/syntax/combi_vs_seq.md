# Combi VS Seq

組合せ回路と順序回路はデジタル回路の基本的な分類の一つ。

時間依存性があるかどうかで異なる。


## 組合せ回路

### 概要

- 入力の値のみで出力が即座に決まる回路
- 時間や過去の状態に依存しない
- 入力が変われば、即、出力も変化する

### 代表例

- ANS/OR/NOT/XOR回路
- 加算器(adder)
- デコーダ(Decorder)
- マルチプレクサ(Multiplexer)

以下のように入力が決まれば毎回同じ計算をする。

| 入力 | 出力 |
| ---- | ---- |
| 000  | 0    |
| 001  | 1    |
| 010  | 0    |
| 111  | 1    |


## 順序回路

### 概要

- 現在の入力のみならず、過去の状態にも依存する回路
- 記憶素子(フリップフロップ、ラッチなど)を含む
- クロック信号で状態を更新する

### 代表的な例

* フリップフロップ（Flip-Flop）
* カウンタ（Counter）
* レジスタ（Register）
* 状態機械（State Machine, FSM）


| クロック | 入力D | 出力Q |
| -------- | ----- | ----- |
| ↑       | 0     | 0     |
| ↑       | 1     | 1     |
| ↑       | 1     | 1     |
| ↑       | 0     | 0     |


## 比較表

| 比較項目       | 組合せ回路       | 順序回路                  |
| -------------- | ---------------- | ------------------------- |
| 出力の決定要因 | 現在の入力       | 現在の入力 + 過去の状態   |
| 記憶素子       | なし             | あり（FF, ラッチ）        |
| クロック依存性 | なし             | あり                      |
| 遅延の原因     | ゲート伝搬時間   | ゲート伝搬 + クロック周期 |
| 例             | AND, OR, Decoder | Counter, Register, FSM    |


### 例での対比

#### 組合せ回路（例：7セグメントデコーダ）

→ 入力の3bit値によって即座に表示パターン（a〜g）が決まる。

#### 順序回路（例：フリップフロップ）

→ クロックが来た瞬間に入力値を**保持**し、次のクロックまで維持する。

では、「 **組合せ回路** 」と「 **順序回路** 」の**違いを時間軸で直感的に理解できるタイムチャート図**で説明します。

---

## 🧮 ① 組合せ回路（例：AND回路）

### 構成

```
y = a AND b
```

### タイムチャート

| 時間(ns) | 信号a | 信号b | 出力y（a AND b） |
| -------- | ----- | ----- | ---------------- |
| 0        | 0     | 0     | 0                |
| 10       | 1     | 0     | 0                |
| 20       | 1     | 1     | 1 ⬅ 即時反映    |
| 30       | 0     | 1     | 0                |
| 40       | 1     | 1     | 1                |

🧠 **特徴**

* 入力が変わるたびに**すぐ出力が変化**する。
* 「過去の状態」は関係なし。
* 遅延は「論理ゲートの伝搬時間（nsオーダー）」のみ。

---

## ⏱ ② 順序回路（例：Dフリップフロップ）

### 構成

```
Q <= D （クロック立上り時に取り込む）
```

### タイムチャート

| 時間(ns) | クロック(clk) | 入力D | 出力Q（次状態）  | 動作     |
| -------- | ------------- | ----- | ---------------- | -------- |
| 0        | 0             | 0     | 0                | 初期状態 |
| 5        | ↑ (立上り)   | 1     | 1 ⬅ Dを取り込む |          |
| 10       | 0             | 0     | 1                | Q保持    |
| 15       | ↑            | 0     | 0 ⬅ Dを取り込む |          |
| 20       | 0             | 1     | 0                | Q保持    |
| 25       | ↑            | 1     | 1 ⬅ Dを取り込む |          |

🧠 **特徴**

* **クロック立上り時にだけ** D の値を取り込む。
* それ以外の時間は、入力が変わっても  **出力は保持** 。
* 過去の取り込み結果（状態）を「記憶」している。

---

## 🔍 両者の比較イメージ（視覚的）

```
時間 →
組合せ回路:   入力──┐     ┌───┐   ┌───────
出力────────┘─────┘───┘───────  （すぐ追従）

順序回路:     入力──┐     ┌───┐   ┌───────
クロック───↑────↑────↑────↑────
出力──────────┐────┘────┐────┘  （クロックで更新）
```

---

## 💬 まとめ（もう一度）

| 比較項目     | 組合せ回路           | 順序回路                 |
| ------------ | -------------------- | ------------------------ |
| 出力依存     | 現在の入力のみ       | 現在の入力 + 過去の状態  |
| 記憶素子     | なし                 | あり（FFやラッチ）       |
| クロック信号 | 不要                 | 必要                     |
| 出力変化     | 入力変化に即応       | クロックで変化           |
| 主な用途     | 演算・変換・制御信号 | 記憶・カウンタ・状態機械 |
