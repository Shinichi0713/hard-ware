## **ALTPLLとは**

### **基本概念**

* **正式名称** : Altera Phase-Locked Loop
* **用途** : クロック生成・管理用のハードウェアIPコア
* **対象デバイス** : Cyclone、Arria、Stratix、MAX10シリーズ

### **主な機能**

* **周波数合成** : 入力クロックから異なる周波数を生成
* **位相制御** : クロック信号の位相調整
* **ジッタ除去** : クロック信号のノイズ除去
* **クロック分配** : 複数の同期クロック出力

## **ALTPLLの構成要素**

### **内部ブロック**

```
入力クロック → 位相検出器 → ループフィルタ → VCO → 出力クロック
     ↑                                      ↓
     └── フィードバック分周器 ←── 出力分周器 ←┘
```


### **主要パラメータ**

1. **入力周波数範囲** : デバイスにより異なる（通常5MHz〜800MHz）
2. **出力周波数範囲** : VCO周波数に依存
3. **分周比** : 整数分周およびフラクショナル分周
4. **位相シフト** : 0°〜360°の位相調整
5. **デューティサイクル** : 50%以外の設定も可能


## **ALTPLLの設定パラメータ**

### **基本設定**

```
ALTPLL #(
    .bandwidth_type("AUTO"),
    .clk0_divide_by(2),          // 出力分周比（分母）
    .clk0_duty_cycle(50),        // デューティサイクル
    .clk0_multiply_by(1),        // 出力倍数比（分子）
    .clk0_phase_shift("0"),      // 位相シフト
    .inclk0_input_frequency(20000), // 入力周波数（ps単位）
    .intended_device_family("MAX 10"),
    .operation_mode("NORMAL"),
    .pll_type("AUTO")
) pll_inst (
    .inclk0(ref_clk),    // 基準クロック入力
    .areset(reset),      // 非同期リセット
    .c0(out_clk0),       // 出力クロック0
    .locked(pll_locked)  // PLLロック信号
);
```


## **ALTPLLの出力種類**

### **クロック出力**

* **c0〜c5** : 最大6個の独立したクロック出力
* **各出力で異なる周波数・位相設定可能**

### **制御信号**

```vhd
-- 主要な入出力ポート
port (
    -- 入力
    inclk0          : in  std_logic;  -- 基準クロック
    inclk1          : in  std_logic;  -- 代替基準クロック（オプション）
    areset          : in  std_logic;  -- 非同期リセット
  
    -- 出力
    c0, c1, c2, c3  : out std_logic;  -- クロック出力
    locked          : out std_logic;  -- PLLロック状態
  
    -- 高度な制御（オプション）
    clkswitch       : in  std_logic;  -- クロック切り替え
    pllena          : in  std_logic;  -- PLL有効制御
    fbin            : in  std_logic   -- 外部フィードバック
);
```


## **ALTPLLの動作モード**

### **1. NORMAL Mode**

* **標準的なPLL動作**
* **最も一般的な用途**
* **シンプルな設定**

### **2. EXTERNAL_FEEDBACK Mode**

* **外部フィードバック使用**
* **クロックスキューの最小化**
* **高精度タイミング要求時**

### **3. ZERO_DELAY_BUFFER Mode**

* **入出力間の遅延最小化**
* **クロック分配用途**

### **4. SOURCE_SYNCHRONOUS Mode**

* **ソース同期設計用**
* **データとクロックの同期**

## **ALTPLLの利点**

### **技術的利点**

1. **高精度** : 低ジッタ、高安定性
2. **柔軟性** : 多様な周波数設定
3. **統合性** : FPGA内蔵で外部部品不要
4. **制御性** : 動的な周波数・位相制御

### **設計上の利点**

1. **簡単な設定** : GUIベースの設定
2. **自動最適化** : デバイスに応じた最適化
3. **シミュレーション対応** : ModelSimでの動作検証
4. **ツール統合** : Quartus Primeとの完全統合

## **使用時の注意点**

### **設計制約**

1. **リソース使用** : PLLブロック数に制限
2. **VCO範囲** : 内部VCOの周波数制限
3. **電源ノイズ** : アナログ回路のため電源品質重要
4. **温度特性** : 温度による周波数ドリフト

### **タイミング考慮**

1. **ロック時間** : 安定化に数μs〜数ms必要
2. **リセット制御** : 適切なリセットシーケンス
3. **クロック制約** : SDCファイルでの制約設定
4. **CDC処理** : 異なるクロックドメイン間の処理
