SystemVerilogのコーディングスキルを磨くための練習問題を、難易度別に提供します。これらの問題は、デジタル設計の基本、検証の概念、およびSystemVerilog特有の機能をカバーしています。

---

## 💻 SystemVerilog コーディング練習問題

### ⭐️ 初級編: 基本的な組み合わせ回路とシーケンシャル回路

これらの問題は、SystemVerilogの基本的な文法と、単純なデジタル回路のモデリングに慣れることを目的としています。

1. **優先度エンコーダの設計:**
   * **要件:** 4ビットの入力 `in[3:0]` を受け取り、最も優先度の高い（最上位ビット側の）'1'に対応する2ビットの出力 `out[1:0]` と、有効を示す `valid` ビットを出力する**組み合わせ回路** `priority_encoder_4x2` を設計してください。`in` が全て '0' の場合、`valid` は '0' とします。
   * **ヒント:** `always_comb` ブロックと `if/else if` または `case` ステートメントを使用します。
2. **Dフリップフロップ配列の設計:**
   * **要件:** 8ビットのデータ入力 `d[7:0]`、クロック `clk`、非同期リセット `rst_n` (Lowアクティブ) を持つ8ビットレジスタ `d_ff_array` を設計してください。リセット時、出力 `q` は '0' にクリアされるものとします。
   * **ヒント:** `always_ff` ブロックを使用し、リセット条件とクロックエッジを正しく記述します。
3. **状態遷移のモデリング (FSM):**
   * **要件:** 以下の3つの状態を持つ単純なFSM（有限状態機械）を設計してください。
     * `IDLE` (00) -> `WAIT` (01) -> `READY` (10) -> `IDLE` へと遷移します。
   * 入力はクロック `clk` とリセット `rst_n` のみとし、外部入力による遷移条件は不要とします。
   * **ヒント:** `typedef enum` を使用して状態を定義し、組み合わせロジックとシーケンシャルロジックを分離して記述します。

## 🔷 中級編: データ処理とテストベンチの概念

これらの問題は、より複雑なデータ操作と、検証のための基本的なテストベンチの記述を練習することを目的としています。

4. **固定小数点演算器のモデリング:**
   * **要件:** 8ビット整数部と8ビット小数部を持つ **$16$** ビット固定小数点数 `data_a` と `data_b` を入力とし、それらの積（乗算結果）を出力する `fixed_point_multiplier` モジュールを設計してください。出力は **$32$** ビット（整数部 **$16$** ビット、小数部 **$16$** ビット）とします。
   * **ヒント:** 整数部の乗算と小数点の位置調整を考慮して、適切なビット幅で計算します。
5. **FIFO（First-In, First-Out）のテストベンチ:**
   * **要件:** 既にある `$4 \times 8$ ビットの非同期FIFO` モジュール（`fifo_unit` と仮定）を検証するためのシンプルなテストベンチ `fifo_tb` を記述してください。
   * テストベンチは、以下のシーケンスを実行するものとします。
     1. FIFOをリセットする。
     2. 5つの異なるデータ（例: 'hAA, 'hBB, ...）を FIFO に書き込む。
     3. FIFO が満杯ではないことを確認する。
     4. 書き込んだデータを順番通りに5つ読み出す。
     5. 読み出したデータが期待値と一致しているか確認する。
   * **ヒント:** `initial` ブロック、`fork-join` または `@(posedge clk)` を使用してタイミングを制御します。

## 💎 上級編: 高度な検証機能と抽象化

これらの問題は、UVM（Universal Verification Methodology）の概念につながる、SystemVerilogの高度な機能（インターフェース、アサーション、クラス）を扱うことを目的としています。

6. **モデム・インターフェースの作成:**
   * **要件:** クロック `clk` とリセット `rst_n`、および以下の信号を持つ**インターフェース** `modem_if` を定義してください。
     * データバス (8ビット) `data`
     * 送信要求 `tx_req` (出力)
     * 受信準備完了 `rx_rdy` (入力)
   * このインターフェース内に、以下の2つの**モッドポート (modport)** を定義してください。
     * `SENDER` modport: `tx_req` を出力、`data` を出力、`rx_rdy` を入力とする。
     * `RECEIVER` modport: `tx_req` を入力、`data` を入力、`rx_rdy` を出力とする。
   * **ヒント:** インターフェースにより、DUTとテストベンチの接続を抽象化します。
7. **トランザクション・クラスの定義:**
   * **要件:** パケットベースの通信をシミュレートするための **クラス** `packet_transaction` を定義してください。
   * クラスは以下のプロパティを持つものとします。
     * `rand int id;` (ランダムなパケットID)
     * `rand int length;` (ランダムなデータ長、制約で **$1$** から **$16$** の間に制限)
     * `rand byte payload[];` (ランダムなデータペイロード、`length` に依存)
   * さらに、`payload` 配列のサイズを `length` と一致させるための**制約 (constraint)** を追加してください。
   * **ヒント:** `rand` キーワード、動的配列、`constraint` ブロックを使用します。

これらの問題を解くことで、SystemVerilogを用いたHDL設計と検証の両方のスキルが向上します。頑張ってください！
