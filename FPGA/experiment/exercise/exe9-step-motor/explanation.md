# 目的

FPGAよりステップモータを使った制御の練習を行う

## 構成

FPGA は **高精度なパルス生成やタイミング制御** が得意なので、ステッピングモータの駆動にとても向いています。

---

## ✅ ステッピングモータ駆動の基本構成

```
        ┌────────────┐
        │  FPGA      │
        │            │
        │ ・ステップパルス生成  ── STEP ──┐
        │ ・回転方向制御      ── DIR  ──┤
        │ ・マイクロステップ設定 ── MSx ─┤
        │ ・速度(加減速)制御              │
        └────────────┘
                  │
                  ▼
          ┌─────────────┐
          │ モータドライバ │  (例: A4988 / DRV8825)
          │ ・電流制限
          │ ・Hブリッジ駆動
          └─────────────┘
                  │
                  ▼
          ステッピングモータ
```

---

### 1. **FPGA 側でやること**

* **STEP 信号生成**
  * 一定周期のパルスを出して回転させる
  * 周波数を変えると回転速度が変わる
* **DIR 信号**
  * HIGH / LOW で回転方向を切り替える
* **加減速制御**
  * いきなり高速にすると脱調するので、パルス周期を段階的に短くするランプ制御を実装
* **マイクロステップ設定** （必要なら）
* ドライバの MS1, MS2, MS3 ピンを制御して細かいステップ角を設定
* **回転数設定**
  * FPGA 内部でカウンタを使い、任意の周波数のパルスを生成

👉 HDL（VHDL / Verilog）で「クロック分周」と「ステップパルスの周波数制御回路」を作ります。

---

### 2. **モータドライバ側でやること**

* モータの**コイルを大電流で駆動する**部分は専用ドライバIC（A4988, DRV8825 など）に任せます。
* FPGAからは **STEP/DIR/MSピン** だけを与えればOK。
* ドライバ内部はHブリッジや電流制御回路が入っていて、FPGA単体より安全・簡単にモータを動かせます。

---

### 3. **電源**

* ステッピングモータ用の電源（12Vや24Vなど）を別途用意。
* FPGAはロジック電圧（3.3V/2.5V/1.8Vなど）で動作するので、**ロジック電圧とモータ電源は分ける**のが一般的。

---

### 4. **センサ（必要に応じて）**

* **リミットスイッチ** （原点検出）
* **エンコーダ** （回転フィードバック、オープンループ防止用）

  → FPGAの入力ポートに接続し、位置補正や安全停止に使う。

---

## ✅ FPGA 内部での HDL 実装イメージ（Verilog例）

```verilog
module stepper_ctrl(
    input  wire clk,        // FPGAの基準クロック (例:50MHz)
    input  wire reset_n,
    input  wire [31:0] speed_setting, // パルス周期設定値
    output reg  step,
    output reg  dir
);

reg [31:0] counter;

always @(posedge clk or negedge reset_n) begin
    if (!reset_n) begin
        counter <= 0;
        step <= 0;
        dir <= 0; // 0:正転,1:逆転
    end else begin
        if (counter >= speed_setting) begin
            counter <= 0;
            step <= ~step;  // パルス生成
        end else begin
            counter <= counter + 1;
        end
    end
end

endmodule
```

* `speed_setting` を変えることでパルス周期を調整し、モータ速度を変えられます。

---

## ✅ よくある拡張機能

* **加減速テーブルを持つ**

  → スムーズに加速・減速する
* **リミットスイッチ入力**

  → 原点復帰・安全停止
* **複数軸制御**

  → CNC / ロボット用
* **エンコーダフィードバック**

  → 脱調を検出して補正（クローズドループ化）

---

## ✅ まとめ

* FPGA は「高精度なパルス生成」「複雑なタイミング制御」が得意なので、

  ステッピングモータの **STEP/DIR 信号生成** に最適。
* **モータドライバIC** （A4988, DRV8825など）を使えば大電流駆動が安全。
* 加減速やリミットスイッチなどもFPGAロジックに簡単に組み込める。
